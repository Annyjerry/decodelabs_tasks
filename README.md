# DecodeLabs AI Internship Training Program

Welcome to the DecodeLabs Artificial Intelligence Internship Training repository! This repository contains practical exercises designed to build foundational knowledge in machine learning and AI decision-making systems.

---

##  Project Overview

This internship training program consists of two progressive tasks that introduce core concepts in Artificial Intelligence and Machine Learning:

1. **Rule-Based Chatbot** - Understanding decision-making through conditional logic
2. **Titanic Survival Prediction** - Building a predictive model using Logistic Regression

Each task is designed to strengthen your understanding of how AI models process information and make predictions.

---

##  Learning Objectives

- Understand how AI models make decisions using conditional logic (IF statements)
- Learn the fundamentals of supervised machine learning
- Implement and train a classification model (Logistic Regression)
- Practice data preprocessing and model evaluation
- Develop skills in Python programming for machine learning

##  Task Details

### Task 1: Rule-Based Chatbot

**Objective:** Understand how AI models make decisions using IF statements

**Description:**
This task involves building a simple rule-based chatbot that demonstrates how artificial intelligence can make decisions based on predefined rules and conditional logic. By analyzing user input and applying a series of IF-ELSE statements, the chatbot learns how decision-making in AI systems works at a fundamental level.

**Key Concepts:**
- Conditional logic (IF/ELSE statements)
- Pattern matching and string processing
- User input handling
- Rule-based decision systems

**File:** `Task1.py`

**How to Run:**
```bash
python Task1.py
```

---

### Task 2: Titanic Survival Prediction

**Objective:** Build a predictive model using Logistic Regression

**Description:**
This task involves analyzing the famous Titanic dataset and building a machine learning model to predict whether a passenger would have survived the disaster. Using Logistic Regression, a fundamental classification algorithm, you'll learn how to:
- Explore and preprocess real-world data
- Handle missing values and feature engineering
- Train and evaluate a classification model
- Make predictions on new data

**Key Concepts:**
- Data exploration and visualization
- Data preprocessing and feature engineering
- Logistic Regression classification
- Model evaluation and performance metrics
- Supervised learning workflow

**Files:** 
- `Task2.ipynb` - Interactive Jupyter notebook with detailed explanations
- `task2.py` - Python script implementation

**How to Run:**

*Option 1: Jupyter Notebook (Recommended for learning)*
```bash
jupyter notebook Task2.ipynb
```

*Option 2: Python Script*
```bash
python task2.py
```

- Python 3.7 or higher
- pip (Python package manager)

```
numpy

matplotlib
seaborn
jupyter
```

### Installation Steps

1. Clone the repository:
```bash
git clone https://github.com/Annyjerry/decodelabs_tasks.git
cd decodelabs_tasks
```


```bash

```

##  Dataset Information

### Titanic Dataset
- **Source:** Kaggle Titanic: Machine Learning from Disaster
- **Size:** 891 records (training set)
- **Features:** 11 attributes including PassengerId, Pclass, Name, Sex, Age, SibSp, Parch, Ticket, Fare, Cabin, Embarked
- **Target:** Survived (0 = No, 1 = Yes)
